# Creative review

Check legibility, hierarchy, call-to-action visibility, spelling, text overflow, safe areas, contrast, captions and mobile presentation as applicable. Check claims against the supplied approved wording and domain advisory. Identify sources and usage rights for external assets and consent for a real person's likeness. Call out checks that require a rendered preview rather than reporting them as passed from a text brief. Return concrete fixes, remaining risks and the exact version or variant reviewed.
