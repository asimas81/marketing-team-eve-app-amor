# Creative brief

Record the Workspace, Product, Campaign and source references when supplied. State objective, audience, offer, key and supporting messages, call to action, target channels and formats, brand and domain constraints, permitted claims, required and prohibited elements, language, dimensions or duration, number of variants and success metric. Mark fields without an approved source as open questions.

For each output, specify its relation to the source artifact and the reviewable form: image concept, carousel sequence, video script/storyboard, product book page plan or landing page design spec. Keep each output separate so a future Marketing OS can store, version and approve it independently. If rendering tools are unavailable, return complete production instructions and label them as specifications.
